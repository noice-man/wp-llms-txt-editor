# История изменений

## 1.2.0 — 2026-10-09

- Автоматическая проверка заголовков публичного `/llms.txt` из админки: `Content-Type`, `charset`, HTTP-код ответа.
- Инструкция для Nginx при отсутствии или неправильной кодировке.
- Кнопка с явным согласием на альтернативную выдачу через WordPress без изменения конфигурации сервера.
- Предварительный тест маршрутизации `.txt`, резервное копирование и проверка нового публичного URL; при неуспехе — автоматический откат.
- Кнопка возврата к физическому файлу и попытка его восстановления при штатной деактивации.
- Открытие опубликованного файла со случайным query-параметром для обхода кэша браузера/сервера.

## 1.1.1 — 2026-10-09

- После сохранения редактор и текст остаются на странице.
- Уведомление об успешной записи, ссылка открытия файла.

## 1.1.0 — 2026-10-09

- Правило UTF-8 для Apache через `.htaccess`, инструкция для Nginx.
- Проверка входного текста на UTF-8.

## 1.0.0 — 2026-10-09

- Создание и редактирование физического `/llms.txt` через админку WordPress.
