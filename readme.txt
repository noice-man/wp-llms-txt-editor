Редактор файла llms.txt в админке WordPress. Создаёт физический файл в корне сайта.

== Description ==

Минималистичный плагин для создания и редактирования /llms.txt.
Автор: Valery Molodtsov. Сайт: https://ворд-пресс.рф

* Отдельный пункт LLMS.txt слева в админке.
* Сохранение в UTF-8 без BOM; физический файл на сервере.
* После сохранения редактор остаётся открытым, показывается уведомление и ссылка на файл.
* Попытка настроить правильную UTF-8 выдачу на Apache; Nginx требует настройки сервера.

== Installation ==

1. Установите ZIP через Плагины → Добавить новый → Загрузить плагин.
2. Активируйте LLMS.txt Editor.
3. Откройте пункт LLMS.txt и отредактируйте текст.
