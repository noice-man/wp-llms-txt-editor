Создаёт и редактирует llms.txt из админки WordPress. Проверяет charset и предлагает безопасную альтернативу настройке Nginx.

== Description ==

* Отдельный пункт LLMS.txt в левом меню админки.
* По умолчанию физический файл /llms.txt, UTF-8 без BOM.
* Проверка HTTP Content-Type и charset.
* Инструкция по настройке Nginx, если UTF-8 не объявлен.
* По согласию администратора — виртуальная выдача через WordPress с заголовком UTF-8. Сначала проверяется доступность .txt-маршрута, после переключения проверяется результат. При неудаче физический файл восстанавливается.
* Сохранение редактора без исчезновения поля; ссылка открытия файла с обходом кэша.

Если Nginx не передаёт отсутствующие .txt в WordPress, виртуальный режим недоступен без перенастройки хостинга.

== Installation ==

Загрузите ZIP через Плагины → Добавить новый → Загрузить плагин. Откройте LLMS.txt в меню.
